# 敲敲乐 · 小朋友的音乐键盘

一个给幼儿"乱按键盘"用的网页：按任何一个键，都会有小动物/小车/恐龙蹦出来唱歌。

**单文件、零依赖、可离线运行。** 所有图案都是 canvas 实时绘制的矢量动画角色，所有声音都是 Web Audio API 实时合成——不加载任何图片和音频文件。

```
keyboard-kids.html        ← 主程序（唯一必需文件）
启动儿童键盘.command       ← macOS 一键启动（Chrome 全屏模式）
keyboard-sounds.html      ← 早期版本（6 音色 + 钢琴键盘，供大孩子/成人玩）
```

## 快速开始

**方式一：一键启动（推荐，孩子拿不出去）**

macOS 下双击 `启动儿童键盘.command`，会以 Chrome `--kiosk` 全屏模式打开：没有地址栏、没有标签页、Esc 退不出去。家长退出按 `Command + Q`。

首次双击若提示"无法验证开发者"：右键 → 打开 → 再点打开；或在终端执行一次：

```bash
xattr -d com.apple.quarantine "./启动儿童键盘.command"
```

**方式二：普通窗口**

直接双击 `keyboard-kids.html`，用任意现代浏览器打开即可。

**方式三：终端命令**

```bash
open -na "Google Chrome" --args --kiosk "file:///绝对路径/keyboard-kids.html"
```

> 打开后先随意敲一下键盘或点一下页面——浏览器规定必须有用户操作才允许播放声音。

## 功能

### 6 套可切换主题

| 主题 | 场景 | 字母键图案 |
|---|---|---|
| 🐾 动物乐园 | 蓝天草地、太阳彩虹 | 猫、狗、兔、熊猫、蝴蝶、蜜蜂…… |
| 🚀 太空探险 | 深蓝星空、星球 | 火箭、飞碟、机器人、宇航员…… |
| 🍭 糖果彩虹 | 马卡龙色、糖果云 | 棒棒糖、蛋糕、甜甜圈、冰淇淋…… |
| 🐬 海底世界 | 海洋蓝、沙质海底 | 鱼、章鱼、螃蟹、水母、海龟…… |
| 🚗 汽车城 | 蓝天、柏油路面 | 小汽车、巴士、警车、红绿灯…… |
| 🦖 恐龙乐园 | 丛林绿、火山 | 霸王龙、翼龙、恐龙蛋、化石…… |

切换主题时，页面配色、键盘配色、舞台场景、角色造型、提示语全部同步更换。

### 图案是"活的"

超过 30 种程序化绘制的动画角色，每种自带循环动画：

- 鱼摆尾、章鱼触手波动、螃蟹双钳开合、水母伞盖脉动
- 车轮滚动、红绿灯循环点亮、火箭尾焰抖动
- 恐龙跺脚、蝴蝶扇翅、蜜蜂振翅、机器人眨眼
- 棒棒糖螺旋旋转、蛋糕烛火摇曳、花朵花瓣旋转

按下的角色会带着自身动画落到舞台上持续蹦跳（重力、反弹、落地挤压、空中翻滚），8–11 秒后淡出。键盘上 59 个按键的图标也是同一套角色实时绘制，是动的，不是贴图。

### 4 种可切换音色

全部由振荡器、滤波器、噪声与包络实时合成：

| 音色 | 听感 |
|---|---|
| 🎵 木琴 | 清脆跳跃、颗粒感强 |
| 🎁 八音盒 | 梦幻柔和、余音长 |
| 🎹 钢琴 | 饱满、有琴弦共鸣 |
| 🎛️ 电子 | 明亮、游戏机感 |

选择会存入 localStorage，下次打开保持。

### 乱按也不难听

所有按键的音高都约束在 **C 大调五声音阶**内：

- 字母键 → 高音区（C4 起）
- 数字键 → 低音区（C3 起）
- 空格 → C3 根音 + G3 五度叠加
- Tab / 回车 / 方向键 / 修饰键 → 各有固定音高

孩子随机乱按，听起来也像在即兴弹奏。

### 针对"瞎乱按"的防护

- **永久禁用顶部一排**：`esc`、`F1`–`F12`、`delete`/`backspace`——这几个键会退出全屏、触发系统亮度音量、误删内容。屏幕键盘上这一排显示为灰色小锁，点了也不响。
- **浏览器后退拦截**：触摸板双指轻扫、`⌥ + ←` 都会被拉回。
- **关闭/刷新确认**：仅在儿童锁开启时弹出。
- **屏蔽右键菜单、捏合缩放、双指滚动、下拉刷新、划词选中**。
- **🔒 儿童锁**：一键进入全屏，状态持久化；被 Esc 顶出全屏后自动抢回并显示"点一下回到全屏"遮罩；解除需长按 1.5 秒，防误触。

## 家长控制

顶栏从左到右：主题切换 → 🎵 音色 → 🔒 儿童锁 → 计数器 → 音量滑块 → 🔇 静音。

## 技术实现

- **音频**：Web Audio API。每种音色由多组振荡器（正弦/三角/锯齿）+ 双二阶滤波器 + 噪声瞬态 + ADSR 包络合成，无采样文件。
- **渲染**：Canvas 2D。双画布分工——舞台层（角色、粒子、环境、地面）60fps，键盘图标层 30fps。所有角色由路径指令程序化绘制，不含位图。
- **布局**：CSS 变量驱动的响应式键盘，键宽按 14 键行铺满屏宽，总高度受 50vh 约束。
- **兼容**：Chrome / Edge / Safari / Firefox 现代版本。macOS 全键支持（含 ⌘ ⌥ ⌃ fn 与方向键）。

### 已知限制

- `⌘W`（关标签）、`⌘Q`（退浏览器）、`⌃⌘F`（macOS 系统全屏切换）属于浏览器/系统级快捷键，**任何网页都无法拦截**，只能靠全屏模式（kiosk）减少接触。
- macOS 的 `Fn` 键和亮度/音量键不产生 DOM `keydown` 事件，无法发声。
- 首次打开需一次用户交互才会启用音频（浏览器安全策略）。
